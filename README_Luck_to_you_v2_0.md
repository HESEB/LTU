# 🍀 Luck to you v2.0

**Selfmaker Company**

> Build your Engine. Save your Research.

Luck to you v2.0은 숫자 조합을 단순히 생성하는 앱이 아니라, 사용자가 자신만의 **생성 엔진**을 만들고 저장하고 비교하는 개인 연구 플랫폼입니다.

---

## 핵심 개념

Luck to you는 고정된 하나의 방식이 아니라, 여러 개의 엔진을 만들어 비교하는 구조입니다.

```text
역대 전체 기록
+
최근 N회 보정
+
엔진 설정
=
생성 결과
```

v2.0에서는 **역대 전체 기록을 기본 데이터**로 사용하고, 사용자는 최근 기준 구간과 엔진 성향을 조정합니다.

---

## 주요 기능

- 엔진 생성
- 엔진 복제
- 엔진 삭제
- 엔진 즐겨찾기
- 캐릭터 선택
- 엔진 이름 변경
- 엔진별 메모
- 생성 결과 저장
- 엔진 비교
- 연구노트
- 백업/복원
- Engine Core v2.0 구조 예약

---

## 엔진 설정

각 엔진은 독립적인 설정을 가집니다.

- 최근 기준 구간: 10회 / 20회 / 30회 / 50회 / 100회
- 최근 구간 보정
- 역대 전체 반영
- Hot 성향
- Cold 성향
- 홀짝 균형
- 구간 균형
- 연속수 허용/감소/제거
- 직전 기록 겹침 허용/감소/제거
- 생성 세트 수

---

## Engine Core v2.0

v2.0의 Engine Core는 역대 전체 기록을 기본 데이터로 사용합니다.

회차 기록이 갱신되면 내부 기준 데이터가 자동 재계산되고, 각 엔진은 해당 기준 위에 사용자의 설정을 반영하여 결과를 생성합니다.

```text
Engine Core v2.0
- 역대 전체 기록 기반
- 최근 N회 보정 지원
- 엔진 설정 반영
- v3.0 확장 구조 예약
```

Engine Core 편집, 번호 DNA, Pair/GAP/Density 분석은 v3.0에서 확장 예정입니다.

---

## 프로젝트 철학

Luck to you는 특정 결과를 예측하거나 보장하는 도구가 아닙니다.

이 프로젝트의 목적은 **생성 엔진을 설계하고, 기록하고, 비교하며, 자신만의 연구 흐름을 만드는 것**입니다.
